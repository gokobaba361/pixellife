# PixelLife

Pixel Life, şehir yaşamı temalı piksel görünümlü bir yaşam simülasyonu IP'si
olarak tasarlanıyor. Mevcut web prototipi yalnızca erken görsel ve mekanik
referans olarak tutulur. Aktif çalışma odağı Faz 0 GDD'dir.

## Prototipi Çalıştırma

```bash
npm install
npm run dev
```

Yerel adres: http://127.0.0.1:5173

## Şu Anki Prototip

- Şehirde bir lokasyona tıkla.
- Alt aksiyon düğmesine tıkla.
- Zaman, kaynaklar ve görev ilerlemeleri değişir.
- Sağdaki PixelPhone menüsünden görev, çanta ve ilişki durumunu izle.
